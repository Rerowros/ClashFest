## 2023-10-24 - [SSRF in Intent Handling] **Vulnerability:** Unvalidated URL parameter in ExternalControlActivity intent handling. **Learning:** Deep links (intents) processing URIs must validate protocol/schema before accessing them to prevent SSRF or Local File Inclusion via file:// or content:// schemas. Native android.webkit.URLUtil.isNetworkUrl provides an effective, dependency-free validation method for this pattern.
