## 2025-05-24 - [ExternalControlActivity Intent Redirection Risk] **Vulnerability:** Unvalidated URL parameter from external intent used to fetch/install profile. **Learning:** Activities exported with `Intent.ACTION_VIEW` deep links (`clash://install-config`) need strict scheme/URL validation (e.g., using `ShareImportSupport.isAllowedUrlProfileSource`) to prevent unauthorized configuration injection or SSRF.
